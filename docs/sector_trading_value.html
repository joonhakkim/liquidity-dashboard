섹터 이동평균 기간 단위

일별 거래대금

막대 = 일별 거래대금, 선 = 이동평균. 막대가 선 위로 크게 올라오면 평소보다 거래가 몰린 날입니다.

섹터 순위 행을 누르면 위 차트가 바뀌고, 머리글을 누르면 정렬

구성종목 거래대금

계산: 섹터는 '섹터 정리' 엑셀의 종목만 씁니다. 섹터 거래대금 = 소속 종목의 그날 거래대금(코스피·코스닥 정규장+시간외 포함 KRX 일별 매매정보) 합계입니다.
배수 = 그날 거래대금 ÷ 직전 20거래일 평균(그날 제외). 1.5배 이상이면 평소보다 많이 몰린 날, 0.7배 이하면 한산한 날입니다.
시장 대비 % = 섹터 거래대금 ÷ 코스피·코스닥 전체 거래대금. 전체 거래대금이 늘어서 같이 늘어난 것인지, 이 섹터로만 몰린 것인지 가를 때 봅니다.
